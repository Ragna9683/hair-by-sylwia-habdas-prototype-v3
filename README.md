# Hair by Sylwia Habdas · Design V3

Откройте `index.html` в браузере. Шрифты, стили и медиа находятся рядом со страницей.

## Запуск из папки прототипа в PowerShell

~~~powershell
Invoke-Item -LiteralPath ".\index.html"
~~~

В первом экране один широкий снимок салона объединяет пространство вокруг вертикального ролика 9:16. Под ним набрана фраза из биографии «Prawdziwa elegancja nie potrzebuje rozgłosu». Ролик запускается один раз без звука. Кнопка ставит его на паузу, продолжает или повторяет показ. При включённом уменьшенном движении показ начинается вручную со стоп-кадра.

«O nas» разделён на Artysta, Historia и Pracownia. Портрет и акцент «Ponad 20 lat doświadczenia» знакомят с Сильвией, затем идут её профессиональный путь и интерьер студии. Полная биография сохранена в исходном порядке.
